# 스크린샷

루트 [README](../../README.md) 의 「화면」 표가 이 폴더의 파일을 가리킵니다.
아래 이름으로 넣으면 바로 표시됩니다.

| 파일            | 무슨 화면                       |
| --------------- | ------------------------------- |
| `result.png`    | 닮은 품종 판정 결과             |
| `game.png`      | 다마고치 (돌보기 · 스탯 · 성장) |
| `chat.png`      | 대화                            |
| `photo-gen.png` | 기념 사진 생성                  |
| `album.png`     | 앨범                            |
| `ending.png`    | 노년기 엔딩                     |

**폰 화면 그대로**가 좋습니다. 세로가 길어 표에서 나란히 놓기 좋고, 웹 브라우저
창을 찍으면 주소창과 여백이 같이 들어가 지저분해집니다.

`npm start` 로 폰에 띄운 뒤 기기 스크린샷을 찍어 그대로 넣으면 됩니다.
성장 단계나 엔딩처럼 시간이 걸리는 화면은 시연 도구로 건너뛰어 찍으세요
([DEVELOPMENT.md 의 시연 도구](../../DEVELOPMENT.md#시연-도구)).
